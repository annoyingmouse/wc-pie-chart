<wc-pie-chart>

Installation

<script type="module" src="https://unpkg.com/wc-pie-chart/wc-pie-chart.js"></script>

Alternatively

<script type="module" src="https://cdn.skypack.dev/wc-pie-chart/wc-pie-chart.js"></script>

After the next release you can use it minified by adding using this instead:

<script type="module" src="[WHATEVER CDN]/wc-pie-chart/dist/wc-pie-chart.min.js"></script>

Please remember to change [WHATEVER CDN] to your favourite CDN

Examples

Basic Example (my original colours)

Each slice has a label attribute — this is included in the auto-generated aria-label read by screen readers.

<wc-pie-chart duration="3000">
  <wc-pie-slice value="5" label="Red"  color="#E64C65"></wc-pie-slice>
  <wc-pie-slice value="5" label="Teal" color="#11A8AB"></wc-pie-slice>
  <wc-pie-slice value="5" label="Navy" color="#394264"></wc-pie-slice>
</wc-pie-chart>

This has its attributes changed via JS in an external file.

In one case we increase the thickness to 0.5 to create a pie-chart, rather than a donut-chart.

Another basic example

This is an empty div which is populated with this script:

const test = document.getElementById('test')
const segments = Math.floor(Math.random() * 10) + 5;
const newPieChart = document.createElement('wc-pie-chart')
newPieChart.setAttribute('width', '500')
for(let i = 0; i < segments; i++){
  const newPieSlice = document.createElement('wc-pie-slice')
  newPieSlice.setAttribute('value', `${Math.floor(Math.random() * 100) + 1}`)
  newPieChart.append(newPieSlice)
}
test.append(newPieChart)

If you refresh the page, it should change.

This is just me playing with grayscale colours.

The greys are in an array, this script populates the donut-chart with the greys:

const greyChart = document.getElementById('grey')
greys.forEach(grey => {
  const newPieSlice = document.createElement('wc-pie-slice')
  newPieSlice.setAttribute('value', `1`)
  newPieSlice.setAttribute('color', grey)
  greyChart.append(newPieSlice)
})

Accessibility

Auto-generated aria-label

When label attributes are present on slices, the component builds a description automatically. Inspect this element to see the generated aria-label and role="img". 

<wc-pie-chart>
  <wc-pie-slice value="42" label="Cats"  color="#E64C65"></wc-pie-slice>
  <wc-pie-slice value="31" label="Dogs"  color="#11A8AB"></wc-pie-slice>
  <wc-pie-slice value="27" label="Other" color="#394264"></wc-pie-slice>
</wc-pie-chart>
<!-- Produces: aria-label="Pie chart with 3 slices: Cats 42.0%, Dogs 31.0%, Other 27.0%" -->

Custom aria-label

Supply your own aria-label on <wc-pie-chart> to override the auto-generated one — useful when you want to describe the chart's meaning rather than its raw data.

<wc-pie-chart aria-label="Favourite pets survey, 100 respondents">
  <wc-pie-slice value="42" label="Cats"  color="#E64C65"></wc-pie-slice>
  <wc-pie-slice value="31" label="Dogs"  color="#11A8AB"></wc-pie-slice>
  <wc-pie-slice value="27" label="Other" color="#394264"></wc-pie-slice>
</wc-pie-chart>
